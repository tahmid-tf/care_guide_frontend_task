MongoDB Aggregation Pipeline Demos

Specific scenarios required by the technical specification.

Scenario 1

Group Users by Interests

Context: User profiles contain a list of interests (e.g., ['chess', 'reading']).
Constraint: Exactly one collection.aggregate() call using $unwind, $group, and $sort. Supported by multikey index userSchema.index({ interests: 1 }).

Scenario 2

Retrieve User Posts via $lookup

Context: Users write posts stored in a separate Posts collection. Visible to everyone.
Constraint: Single aggregation pipeline with a $lookup stage. Supported by index postSchema.index({ author: 1, createdAt: -1 }).
